Langkah 1 dari 4: Unggah Dokumen

Unggah Dokumen Anda

Pilih atau seret file dokumen yang ingin dicetak. Pastikan file dalam format yang didukung dan ukurannya tidak melebihi batas.

Area Unggah

Pilih Dokumen untuk Dicetak

Format yang diterima: PDF, DOCX, PPTX. Ukuran maksimal: 50 MB.

Digunakan untuk identifikasi saat pengambilan.

Untuk notifikasi pesanan selesai (jika tersedia).

Format File yang Didukung

Daftar format file yang dapat diunggah beserta batasannya
Format Ekstensi Ukuran Maks. Keterangan
PDF Document .pdf 50 MB Direkomendasikan untuk hasil terbaik
Word Document .docx 50 MB Dokumen Microsoft Word 2007+
PowerPoint .pptx 50 MB Presentasi Microsoft PowerPoint 2007+

Tips Sebelum Mengunggah

  • Pastikan dokumen sudah final - tidak ada fitur edit di dalam sistem.
  • Periksa orientasi halaman (portrait/landscape) sebelum unggah.
  • Untuk file lebih dari 20 MB, unggahan mungkin membutuhkan waktu lebih lama.
  • File akan otomatis dihapus dari server setelah pesanan selesai (privasi terjaga).
  • Gunakan format PDF untuk memastikan tata letak tidak berubah saat dicetak.

Pratinjau File yang Dipilih

Belum ada file yang dipilih. Unggah dokumen terlebih dahulu untuk melihat pratinjau.
